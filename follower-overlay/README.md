# TomIconic Live Follower Overlay

Clean transparent OBS browser overlay:
- TikTok logo + live follower count
- Instagram logo + live follower count
- transparent background
- animated number change
- 1920x1080 friendly

## OBS URL

After GitHub Pages is enabled:

https://tomiconicdev.github.io/Test-Game/follower-overlay/

### Browser Source
- Width: 1920
- Height: 1080
- FPS: 30 or 60
- Custom CSS: leave blank

## Quick test

Add counts directly to the URL:

? tiktok=12345&instagram=67890

(remove the space after ?)

Example:
https://tomiconicdev.github.io/Test-Game/follower-overlay/?tiktok=12345&instagram=67890

## Live data

GitHub Pages is static, so the overlay cannot safely hold TikTok/Instagram API secrets in the browser. The overlay therefore accepts a public JSON endpoint:

https://tomiconicdev.github.io/Test-Game/follower-overlay/?data=https%3A%2F%2Fexample.com%2Ffollowers.json

Expected JSON:
{"tiktok":12345,"instagram":67890}

It polls that endpoint every 5 seconds. You can change the interval with &interval=3000.

For true automatic live counts, the JSON endpoint should be generated by a small server/serverless function that talks to the social APIs. Keep API credentials on that server, never in this GitHub Pages code.

TikTok's current developer API exposes follower_count with the appropriate authorised scope; Instagram access depends on Meta/Instagram API access and account setup.
